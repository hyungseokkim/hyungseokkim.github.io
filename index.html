김형석

이탈한 개발자의 프로젝트에 투입되고, 서비스가 종료된 시스템의 데이터를 넘겨받고, 문서 없는 레거시를 분석해 왔습니다. 새로 짓는 일보다 넘겨받은 시스템을 안정적으로 운영 가능한 상태로 만드는 일을 주로 해왔습니다.

Java·PHP 백엔드와 RDBMS를 주력으로, 급여·근로·재무·금융처럼 정확성이 중요한 도메인에서 데이터 이관과 정합성 검증을 반복해 왔습니다.

핵심 역량

문서 없는 시스템을 넘겨받아, 멈추지 않게 만듭니다

01 레거시 인수와 점진적 개선

문서화되지 않은 코드베이스를 분석해 운영을 인수하고, 서비스를 멈추지 않으면서 구조를 개선합니다. PHP 레거시 기능을 REST API로 점진 분리한 경험이 있습니다.

02 비정형 데이터 마이그레이션

엑셀·CSV로 넘어온 정합성이 깨진 데이터를 임시 테이블 적재 → 검증 → 본 테이블 반영의 단계로 이관하고, 오류가 나도 전체가 아닌 행 단위로 실패를 격리합니다.

03 정확성이 중요한 도메인

급여·근로·재무·금융처럼 틀리면 안 되는 데이터를 다뤄왔습니다. 밸리데이션 기준을 데이터 특성별로 분리하고, 자동화 가능한 영역을 구분해 처리합니다.

04 문서화와 협업

Swagger로 API 동작을, Notion으로 시스템 흐름을 문서화해 팀과 공유합니다. 기획·디자인 등 타 직군과 함께 불명확한 요구사항을 정리해 동작하는 결과물로 연결합니다.
